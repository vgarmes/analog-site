Materials needed:

- 500GB SATA2 2.5" HDD
- SATA to USB 3.0 / 2.0 Cable
- Bitfunx Free McBoot V1.966
- BitFunx GameStar SATA Adapter Compatible 2.5 or 3.5 Inches

HDL Batch Installer
Main > Format HDD

For some reason my formatting failed, leaving the HDD uninitialized. I had to use the Windows Disk Management to initialize it as MBR (Master Boot Record). After that, I repated the process and was able to use the HDL Batch Installer to format the HDD properly.

Click on Search PS2 HDD and you should be able to see the HDD listed.
Browse tab > Get list = See the list of installed games in the HDD.
Install tab > Search games (iso) > Install
